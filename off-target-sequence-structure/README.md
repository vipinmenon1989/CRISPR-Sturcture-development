# off-target-sequence-structure — Off-Target Mismatch Alignment

This directory handles the alignment and mismatch characterisation of off-target sequences relative to a given on-target sgRNA.

## Contents

| File | Description |
|------|-------------|
| `align_sequences.py` | Main alignment script — compares off-target DNA sequences to the on-target and reports mismatch count and positions |
| `off_target.txt` | Input file of off-target DNA sequences (one per line), typically from Cas-OFFinder |
| `alignment_results.csv` | Output — per-sequence alignment results (generated by the script) |

## Script: align_sequences.py

### What it does

Given a reference on-target 23-nt DNA sequence and a list of Cas-OFFinder off-target hits:

1. Converts the first 20 nt of the on-target to RNA to define the **guide RNA** (constant across all rows)
2. Processes each off-target DNA sequence from `off_target.txt`
3. Computes position-by-position mismatches (1-based indices) against the on-target
4. Outputs a CSV with DNA sequence, RNA equivalent, guide RNA, mismatch count, and mismatch positions

### Usage

```bash
python align_sequences.py <off_target_file.txt> <on_target_dna>
```

**Example:**
```bash
python align_sequences.py off_target.txt ATGCATGCATGCATGCATGCNGG
```

### Output columns

| Column | Description |
|--------|-------------|
| `DNA_Sequence` | Off-target DNA sequence |
| `RNA_Sequence` | Off-target converted to RNA (T→U) |
| `Guide_RNA` | First 20 nt of on-target as RNA (constant) |
| `Mismatch_Count` | Total number of mismatches vs on-target |
| `Mismatch_Indices` | Semicolon-separated 1-based mismatch positions |

The on-target itself is included as the first row with `Mismatch_Count = 0`.

### Output file

Results are saved to `alignment_results.csv` in the current directory.

## Connecting to the Broader Pipeline

Off-target data for this analysis is generated upstream by **Cas-OFFinder**, using the input file built by `SpCas9_2019/pdb/casmaker.py`. The resulting mismatch profiles can be combined with structural entropy data (from `pdb_files/complete_entropy_pdb.py`) to explore how sgRNA 3-D conformation relates to off-target tolerance.
